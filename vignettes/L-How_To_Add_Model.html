Developing L Modules

Adding Models for Aquatic Mosquito Ecology

This vignette describes how to add a model of aquatic mosquito ecology to ramp.library. Read the ramp.xds L interface vignette first for an overview of how L modules connect to egg laying and emergence. Before adding a module, check whether the model is already available in the SimBA library.

An L module describes aquatic mosquito states in larval habitats. Its methods operate on the habitat dimension, nHabitats, and use s as the vector-species index. The habitat-to-patch membership vector is provided when the module is set up.

Creating a module template

The code chunks below can be extracted to create a starting R file. From the directory containing this vignette, run:

knitr::purl(
  "L-How_To_Add_Model.Rmd",
  output = "Lmodule-newLname.R",
  documentation = 0,
  quiet = TRUE
)

The resulting file contains code examples that must be adapted before the module is used. Replace newLname with a short, model-specific name. When rendered, the chunks define the example functions but do not call them.

General conventions

  • Implement model methods as S3 methods named with the module class, such as dLdt.newLname.
  • Use s to access the module at xds_obj$L_obj[[s]].
  • Store state indices in xds_obj$L_obj[[s]]$ix, with one index per habitat for each habitat-level state.
  • Keep state variables, derivatives, and discrete updates in the same order.
  • Document model equations, states, parameters, inputs, outputs, and references with roxygen.
  • Add tests for the module’s equations, dimensions, and setup behavior.

Module dynamics

Implement dLdt.newLname for a continuous-time model, or Update_Lt.newLname for a discrete-time model. Both receive time t, the dependent-variable vector y, the xds model object, and the species index s. A continuous-time method returns derivatives; a discrete-time method returns updated states. They are alternative solver interfaces, not interchangeable equations.

The habitat-level egg input is available as xds_obj$terms$eta[[s]]. Extract the module states with get_L_vars and use the indices and parameter values stored on the module object.

#' @title Compute derivatives for `newLname` (**L**)
#' @description Implements [ramp.xds::dLdt] for `newLname`.
#' @inheritParams ramp.xds::dLdt
#' @return a numeric vector of derivatives, in state-variable order
#' @export
dLdt.newLname <- function(t, y, xds_obj, s) {
  eta <- xds_obj$terms$eta[[s]]

  with(ramp.xds::get_L_vars(y, xds_obj, s), {
    with(xds_obj$L_obj[[s]], {
      # Replace this expression with the model's derivative equation.
      dL <- rep(0, xds_obj$nHabitats)
      derivatives <- c(dL)
      return(derivatives)
    })
  })
}

If the model has multiple states, extract each state in get_L_vars.newLname, compute each derivative here, and concatenate them in the same order used by setup_L_ix.newLname.

The discrete-time method has the same arguments and returns updated states in that order. Write the model’s discrete update equations directly; do not substitute the continuous-time derivative or an Euler step unless that is the model being implemented.

#' @title Update states for `newLname` (**L**)
#' @description Implements [ramp.xds::Update_Lt] for `newLname`.
#' @inheritParams ramp.xds::Update_Lt
#' @return a numeric vector of updated states, in state-variable order
#' @export
Update_Lt.newLname <- function(t, y, xds_obj, s) {
  eta <- xds_obj$terms$eta[[s]]

  with(ramp.xds::get_L_vars(y, xds_obj, s), {
    with(xds_obj$L_obj[[s]], {
      # Replace this expression with the model's discrete update.
      Lt <- rep(0, xds_obj$nHabitats)
      states <- c(Lt)
      return(states)
    })
  })
}

Bionomics and effect sizes

LBionomics.newLname updates baseline parameter values at time t and resets effect sizes. LEffectSizes.newLname applies the configured effect sizes to those baseline values. Implement these methods for parameters that use time-varying forcing or vector-control effects; use the existing bionomics forcing functions where they match the parameter.

For each affected parameter p1, store its baseline as p1_t, its effect size as es_p1, and its effective value as p1. The example assumes p1_t and p2_t have already been initialized on the module object.

#' @title Mosquito bionomics for `newLname` (**L**)
#' @description Update baseline parameters and reset effect sizes.
#' @inheritParams ramp.xds::LBionomics
#' @return an **`xds`** model object
#' @export
LBionomics.newLname <- function(t, y, xds_obj, s) {
  with(xds_obj$L_obj[[s]], {
    # Replace these assignments with the appropriate forcing functions.
    xds_obj$L_obj[[s]]$p1_t <- p1
    xds_obj$L_obj[[s]]$p2_t <- p2
    xds_obj$L_obj[[s]]$es_p1 <- rep(1, xds_obj$nHabitats)
    xds_obj$L_obj[[s]]$es_p2 <- rep(1, xds_obj$nHabitats)
    return(xds_obj)
  })
}

#' @title Apply effect sizes for `newLname` (**L**)
#' @description Apply vector-control effect sizes to baseline parameters.
#' @inheritParams ramp.xds::LEffectSizes
#' @return an **`xds`** model object
#' @export
LEffectSizes.newLname <- function(t, y, xds_obj, s) {
  with(xds_obj$L_obj[[s]], {
    xds_obj$L_obj[[s]]$p1 <- p1_t * es_p1
    xds_obj$L_obj[[s]]$p2 <- p2_t * es_p2
    return(xds_obj)
  })
}

Module object and setup

make_L_obj_newLname creates the module object and initializes its parameters. setup_L_obj.newLname attaches the object at xds_obj$L_obj[[s]], sets up initial values, and configures habitat search weights using the supplied membership vector.

#' @title Make the `newLname` module object
#' @param nHabitats the number of habitats in the model
#' @param options a named list of parameter values
#' @return an L module object
#' @export
make_L_obj_newLname <- function(nHabitats, options = list(), p1 = 1, p2 = 1) {
  with(options, {
    L_obj <- list(
      p1 = ramp.xds::checkIt(p1, nHabitats),
      p2 = ramp.xds::checkIt(p2, nHabitats),
      p1_t = ramp.xds::checkIt(p1, nHabitats),
      p2_t = ramp.xds::checkIt(p2, nHabitats),
      es_p1 = rep(1, nHabitats),
      es_p2 = rep(1, nHabitats),
      nHabitats = nHabitats
    )
    class(L_obj) <- "newLname"
    return(L_obj)
  })
}

#' @title Set up `newLname` (**L**)
#' @description Implements [ramp.xds::setup_L_obj] for `newLname`.
#' @inheritParams ramp.xds::setup_L_obj
#' @return an **`xds`** model object
#' @export
setup_L_obj.newLname <- function(Lname, membership, xds_obj,
                                 options = list(), s = 1) {
  L_obj <- make_L_obj_newLname(xds_obj$nHabitats, options)
  class(L_obj) <- c("newLname", paste0("newLname_", xds_obj$xds))
  xds_obj$L_obj[[s]] <- L_obj
  xds_obj <- ramp.xds::setup_L_inits(xds_obj, options = options, s = s)
  xds_obj <- ramp.xds::setup_habitat_search_weights(
    "setup", xds_obj, list(membership = membership), s = s
  )
  return(xds_obj)
}

Parameters

Implement get_L_pars.newLname to return the module parameters as a named list, and change_L_pars.newLname to update the parameters named in options while leaving other parameters unchanged. Check supplied values against xds_obj$nHabitats; parameter vectors should match the habitat dimension.

#' @title Get parameters for `newLname` (**L**)
#' @inheritParams ramp.xds::get_L_pars
#' @return a named list of parameters
#' @export
get_L_pars.newLname <- function(xds_obj, s = 1) {
  with(xds_obj$L_obj[[s]], {
    return(list(p1 = p1, p2 = p2))
  })
}

#' @title Change parameters for `newLname` (**L**)
#' @inheritParams ramp.xds::change_L_pars
#' @return an **`xds`** model object
#' @export
change_L_pars.newLname <- function(xds_obj, options = list(), s = 1) {
  nHabitats <- xds_obj$nHabitats
  if ("p1" %in% names(options)) {
    xds_obj$L_obj[[s]]$p1_t <- ramp.xds::checkIt(options$p1, nHabitats)
  }
  if ("p2" %in% names(options)) {
    xds_obj$L_obj[[s]]$p2_t <- ramp.xds::checkIt(options$p2, nHabitats)
  }
  return(xds_obj)
}

State indices and extraction

setup_L_ix.newLname assigns a contiguous range of indices to each state. Allocate one index per habitat for each habitat-level state, and update max_ix after each range. get_L_vars.newLname extracts named states from the dependent-variable vector y.

#' @title Set up state indices for `newLname` (**L**)
#' @inheritParams ramp.xds::setup_L_ix
#' @return an **`xds`** model object
#' @importFrom utils tail
#' @export
setup_L_ix.newLname <- function(xds_obj, s) {
  L_ix <- seq(from = xds_obj$max_ix + 1, length.out = xds_obj$nHabitats)
  xds_obj$max_ix <- utils::tail(L_ix, 1)
  xds_obj$L_obj[[s]]$ix <- list(L_ix = L_ix)
  return(xds_obj)
}

#' @title Extract states for `newLname` (**L**)
#' @inheritParams ramp.xds::get_L_vars
#' @return a named list of state variables
#' @export
get_L_vars.newLname <- function(y, xds_obj, s) {
  with(xds_obj$L_obj[[s]]$ix, {
    L <- y[L_ix]
    return(list(L = L))
  })
}

If the module has more than one state variable, create an index range for each one and include each named state in the returned list.

Initial values

make_L_inits_newLname returns defaults as a named list with one value per habitat for each state. setup_L_inits.newLname stores the list on the module object; users can inspect it with get_L_inits and update it with change_L_inits.newLname.

#' @title Make initial values for `newLname` (**L**)
#' @param nHabitats the number of habitats in the model
#' @param options a named list of initial values
#' @param L the initial value for state `L`
#' @return a named list of initial values
#' @export
make_L_inits_newLname <- function(nHabitats, options = list(), L = 1) {
  with(options, {
    L <- ramp.xds::checkIt(L, nHabitats)
    return(list(L = L))
  })
}

#' @title Set up initial values for `newLname` (**L**)
#' @inheritParams ramp.xds::setup_L_inits
#' @return an **`xds`** model object
#' @export
setup_L_inits.newLname <- function(xds_obj, options = list(), s = 1) {
  xds_obj$L_obj[[s]]$inits <- make_L_inits_newLname(
    xds_obj$nHabitats, options
  )
  return(xds_obj)
}

#' @title Change initial values for `newLname` (**L**)
#' @inheritParams ramp.xds::change_L_inits
#' @return an **`xds`** model object
#' @export
change_L_inits.newLname <- function(xds_obj, options = list(), s = 1) {
  with(options, {
    if (!is.null(L)) {
      xds_obj$L_obj[[s]]$inits$L <- ramp.xds::checkIt(
        L, xds_obj$nHabitats
      )
    }
  })
  return(xds_obj)
}

Emergence

F_emerge.newLname returns a habitat-level vector of adult emergence, usually a rate for a continuous-time model or a number for a discrete-time model. The shared emergence interface aggregates these values to patches using habitat membership.

#' @title Compute emergence for `newLname` (**L**)
#' @inheritParams ramp.xds::F_emerge
#' @return a numeric vector of length `nHabitats`
#' @export
F_emerge.newLname <- function(t, y, xds_obj, s) {
  with(ramp.xds::get_L_vars(y, xds_obj, s), {
    with(xds_obj$L_obj[[s]], {
      # Replace this expression with the model's emergence equation.
      alpha <- rep(0, xds_obj$nHabitats)
      return(alpha)
    })
  })
}

Parsing outputs and optional methods

parse_L_orbits.newLname extracts each state from the solver output matrix, using the indices stored on the module object, and returns a named list. Add derived quantities only when they are useful model outputs.

#' @title Parse outputs for `newLname` (**L**)
#' @inheritParams ramp.xds::parse_L_orbits
#' @return a named list of state-variable orbits
#' @export
parse_L_orbits.newLname <- function(outputs, xds_obj, s) {
  with(xds_obj$L_obj[[s]]$ix, {
    L <- outputs[, L_ix]
    return(list(L = L))
  })
}

steady_state_L.newLname is optional and applies to continuous-time models when a steady-state solution is available. It receives habitat-level egg input eta and returns a named list of steady-state values. The shared get_L_orbits, xds_plot_L, and xds_lines_L functions provide access to and visualization of parsed model output; a module-specific plotting method is not required.

The basicL reference model

The basicL module in ramp.xds is an example of a habitat-level model. It tracks larval density \(L\) and implements

\[\frac{dL}{dt} = \eta - \left(\psi e^{-\xi L} + \phi + \theta L\right)L, \qquad \alpha = \psi e^{-\xi L}L.\]

Its states and parameters each have one value per habitat. Consult aquatic-L-basicL.R in the ramp.xds source for a complete implementation of its setup, parameter, dynamics, initial-value, emergence, and output methods.
